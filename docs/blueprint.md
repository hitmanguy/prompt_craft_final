# **App Name**: ReuniteMe

## Core Features:

- User Authentication: Enable users to create accounts, log in, and manage profiles with secure authentication.
- Report Lost/Found Item: Allow users to submit forms with item details, location, date, and contact information to report a lost or found item.
- Browse Items: Display all submitted items (lost/found) in a searchable and filterable format.
- Item Categorization and AI-Powered Tagging: Automatically categorize items using image recognition and suggest relevant tags to improve searchability; tool identifies important object categories such as electronics, personal items and documents
- Secure Contact Info: Protect user contact information, making it visible only to logged-in users who have a legitimate reason to connect (e.g., claiming a found item).
- User roles: Distinguish access between anonymous users, logged in users and administrators

## Style Guidelines:

- Primary color: Light blue (#A0D2EB) for a calm and trustworthy feel, evoking a sense of security and reliability.
- Background color: Very light blue (#F0F8FF) to provide a clean, neutral backdrop that complements the primary color without overwhelming the user.
- Accent color: Soft orange (#FFB347) to draw attention to important interactive elements, such as buttons and links.
- Headline font: 'Poppins' (sans-serif) for a modern and approachable aesthetic, ensuring readability and a clean visual hierarchy.
- Body font: 'PT Sans' (sans-serif), complementing 'Poppins', for the main text content to ensure a clear and accessible reading experience.
- Use clear, simple icons to represent different item categories and actions, ensuring intuitive navigation.
- Design a clean, mobile-friendly layout with intuitive navigation to ensure ease of use across different devices.
- Incorporate subtle animations, such as fade-in effects, to enhance the user experience and provide feedback for interactions.
